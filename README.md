## 📖 專案簡介
這是一個加強版的 **Python HTTP Server**，支援 **Windows/Linux**，除了基本的檔案存取功能，還提供檔案管理的強化功能。  
你可以用來快速分享檔案，或作為簡易的檔案伺服器使用。

---

## ⚡ 功能特色
- 📥 **下載檔案**  
- 📤 **上傳檔案**  
- 💾 **檢視磁碟大小**  
- ⏰ **更改檔案時間**  
- 📏 **顯示檔案大小**  
- 🗑 **刪除檔案**

---

## 📦 使用方式

### 1️⃣ 查詢電腦 IP
確認兩台電腦在同一個網域內，並找到本機 IP 位址。  

### 2️⃣ 執行方式
- **免安裝版**：解壓縮後，直接執行 `exe` 檔即可（不需安裝 Python）。  
- **原始碼版**：使用 Python 執行（需要安裝 Python 環境）。  

```bash
python server.py
````

### 3️⃣ 瀏覽器連線

打開瀏覽器，輸入以下網址（將 `自己的ip` 替換為實際 IP）：

```
http://自己的ip:8000
```
